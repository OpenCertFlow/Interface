# 전기용품 인증 등급 — 시행규칙 별표 품목

「전기용품 및 생활용품 안전관리법 시행규칙」의 별표에서 추출한 품목 목록입니다.
**인증 등급은 제품군이 아니라 품목 단위로 정해집니다.**

| 별표 | 등급 | 절차 |
|---|---|---|
| 별표 3 | 안전인증대상 | 제품시험 + **공장심사** |
| 별표 4 | 안전확인대상 | 시험성적서 제출 후 신고 |
| 별표 5 | 공급자적합성확인대상 | 제조·수입자가 스스로 확인 |

## 출처와 갱신 방법

법제처 국가법령정보 API로 원문을 받아 별표를 대조했습니다. 재현 절차는
[CONTRIBUTING.md](../../CONTRIBUTING.md)의 "인증 등급을 확인하는 절차"에 있습니다.

```bash
curl -s "https://www.law.go.kr/DRF/lawService.do?OC=$OC&target=law&MST=286389&type=JSON" \
  -o rule.json
```

> **이 문서는 참고 자료입니다.** 법령은 개정되고 이 문서는 그 시점의 사본입니다.
> 룰을 만들 때는 반드시 원문을 다시 확인하세요.

## 읽을 때 주의할 것

**법령의 용어로 찾으세요.** 시행규칙에 "헤어드라이어"는 없습니다. **모발관리기**(별표 3)로
있습니다. 반면 "전기건조기"(별표 4)는 손·발·의류를 말리는 것이고 모발은 포함하지 않습니다.
이름이 비슷해도 별표가 다르면 등급이 다릅니다.

**전원 방식이 등급을 가르는 품목이 있습니다.** 전기찜질기는 교류면 별표 3(안전인증),
직류면 별표 5(공급자적합성확인)입니다. 주방용 전동기기·공기청정기·전격 살충기도 같습니다.

**`—` 표시는 아직 `ApplianceItem`에 없는 품목입니다.** 없다는 것은 이 서비스가 다루지
않는다는 뜻이며, 진단에서는 `OTHER`로 분류되어 전문가 확인으로 안내됩니다. 추가하려면
원문을 다시 확인하고 룰과 테스트를 함께 넣으세요.
